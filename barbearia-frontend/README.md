# BarberFlow — Frontend

Interface web do BarberFlow (React 19 + Vite 7).

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:3000
npm run dev            # http://localhost:5173
npm run build          # gera dist/ (usa .env.production)
npm start              # serve o dist/ com server.cjs (usado no Azure)
```
